## 一、工程材料 · 5 类 18 问

### 1. 性能与指标（考察：概念与标准数值）

- 强度 / 硬度 / 韧性 / 耐磨性怎么区分？
- 防火等级 A、B1、B2、B3 怎么判定？
- 吸水率、导热系数、隔声量多少算合格？
- 耐久性与耐候性：室内外材料怎么选？

### 2. 常用材料认知（考察：知识面与术语）

- 水泥标号、混凝土 C30、砂浆 M5 是什么意思？
- 花岗岩 vs 大理石：区别与各自禁区？
- 钢化 / 夹胶 / 中空玻璃各自的安全场景？
- 乳胶漆、真石漆、艺术漆分别怎么选？
- 木材含水率与防腐处理怎么做？

### 3. 选材与应用（考察：实战判断）

- 为什么选这个材料、不选那个？（对比题）
- 地面 / 墙面 / 台面分别适合什么材料？
- 规格尺寸：踢脚线、护墙板、灯带槽、板材厚度？
- 材料收口与搭配有哪些禁忌？

### 4. 标准与验收（考察：规范意识）

- 材料进场怎么验收、抽检哪些项？
- 板材环保等级 E0 / ENF 怎么核报告？
- 国标、行标（GB / JG/T）去哪查、看哪些参数？

### 5. 新材料与趋势（考察：前沿敏感度）

- 微水泥、软瓷、铝蜂窝板贵在哪、用在哪？
- 绿色低碳建材的政策导向怎么答？

## 二、预算 / 造价 · 5 类 18 问

### 1. 概念体系（考察：基础必背）

- 工程造价由哪些费用构成？
- 概算 / 预算 / 结算 / 决算的区别？
- 定额计价 vs 清单计价？
- 综合单价里含什么？

### 2. 工程量计算（考察：算量规则）

- 面积 / 体积 / 长度按什么规则算？
- 门窗洞口、梁柱要不要扣减？
- 材料损耗率一般取多少（瓷砖、木地板、石材）？

### 3. 价格与费率（考察：市场与取费）

- 人工 / 材料 / 机械费怎么估？
- 管理费、规费、利润、税金的费率？
- 信息价 vs 市场价，以哪个为准？
- 材料涨价 10%，价格怎么调？

### 4. 流程与实操（考察：全流程把控）

- 编一份预算书的步骤是什么？
- 预算超支怎么控、怎么压缩？
- 设计变更 / 签证 / 索赔怎么处理？
- 结算对量对价要盯哪些坑？

### 5. 场景应用（考察：专业落地）

- 室内装修半包 / 全包每平米大概多少钱？
- 景观工程：土方、铺装、绿化、水电怎么拆项？
- 灯光 / 软装 / 家具在预算里占比怎么分？

## 三、综合 / 实战类 · 5 问

> [!warning] 面试与答辩最爱，考临场与算力

- 给你一个 50㎡ 茶室或庭院，现场快速估一个总价
- 客户说"太贵了"：解释预算构成 + 给出压缩方案
- 材料涨价 / 断货，换替代材料影响预算怎么办？
- 图纸漏项、现场增项，结算时怎么处理？
- 环保、安全、耐久三者冲突时怎么权衡？

## 四、最可能被问到的 8 个问题（附答题方向）

1. **工程造价由哪些费用构成？** → 直接费（人材机）＋间接费（管理费、规费）＋利润＋税金，背熟「人材机 + 管利规税」。
2. **概算、预算、结算、决算的区别？** → 按阶段：设计概算 → 施工图预算 → 竣工结算 → 竣工决算，依据和精度逐级不同。
3. **定额计价 vs 清单计价？** → 定额是量价合一、按子目套；清单是量价分离，业主给量、投标报价，综合单价含人材机管利税。
4. **花岗岩 vs 大理石？** → 花岗岩硬、耐候耐酸，适合室外和地面；大理石纹理美但软、怕酸蚀，适合室内墙面和台面。
5. **玻璃怎么选、安全要求是什么？** → 钢化（强度高、碎粒状）、夹胶（防坠落，雨棚/护栏）、中空（保温隔声）；落地窗、门玻璃按规范用安全玻璃。
6. **预算超支怎么控？** → 先查变更签证和漏项，再按「主材价格 / 工艺做法 / 工程量」三处压缩，给分级方案而不是一刀切。
7. **材料损耗率大概取多少？** → 瓷砖 3%~8%、木地板 3%~5%、石材 1.5%~3%（按规格和排版复杂程度浮动）。
8. **现场快速估价怎么做？** → 面积 × 单位造价区间，再拆「硬装 / 主材 / 设备 / 软装」占比校验，主材用当地信息价核对。

## 五、答题速记

> [!tip] 答题套路
> - 材料题：定义 → 关键数值 → 对比 → 带一个项目例子收尾
> - 预算题：费用构成 → 算量规则 → 取费与调价 → 变更/签证风险点
> - 数字给区间并说明口径（如"约 1200–1800 元/㎡，按当地信息价"），不硬编精确值
> - 被问"你怎么做的"：拿出自己项目的一页预算拆分（材料+人工+损耗+管理费税金）
